## 1. 系统概述

辅导员工作台是**只看数据、不做计算**的数据分析平台。数据由秘书处导入综测文件后，辅导员用于：
- 查看年级/班级/学生的综测、绩点、德育等数据
- 多维度对比分析（年级对比、班级对比、学生对比）
- 原始成绩分析（挂科率、课程排名）
- 生成预警名单和家长通知
- 班会大屏展示

## 2. 安装与登录

### 安装
1. 解压分发包到任意位置
2. 右键 `install.ps1` → 「使用 PowerShell 运行」
3. 桌面和开始菜单自动创建快捷方式

### 登录
1. 双击桌面图标启动
2. 登录页输入 `fudaoyuan` / `sdjtu521`

## 3. 界面介绍

### 布局
```
┌──────────────────────────────┐
│ 📗本学期 [文件] 📕上学期    │ ← 数据导入栏
│ 🔍筛选 [年级▼][专业▼][班级▼] │ ← 筛选栏
├───────┬──────────────────────┤
│📊总览  │                      │
│🏫年级  │    主内容区域         │
│📋班级  │                      │
│👤学生  │                      │
│📉成绩  │                      │
│⚠️预警  │                      │
│📧通知  │                      │
│🎯大屏  │                      │
│⚙️设置  │                      │
└───────┴──────────────────────┘
```

左侧为**功能导航栏**，点击切换页面。顶部为**数据导入和筛选栏**。

### 第一步：导入数据

使用辅导员工作台前，需要导入综测文件：

1. 点击顶栏「📗」旁的「选」按钮 → 选择**本学期**综测文件（如 `2025-2026-1综测.xlsx`）
2. 输入学期标签（如 `2025-2026-1`）
3. 点击顶栏「📕」旁的「选」按钮 → 选择**上学期**综测文件
4. 如需更多历史学期，点击「+」按钮添加

导入后，顶栏**筛选器**自动填充年级和专业选项。

### 筛选器使用
- **年级**：如24级、23级
- **专业**：如顿河交、顿河土、顿河信、国电
- **班级**：如顿河交241（会根据年级和专业联动过滤）
- 三个筛选器可组合使用，筛选结果全局生效
- 筛选状态自动保存，下次打开软件自动恢复

## 4. 数据总览

进入工作台后默认显示总览页。

### 核心指标卡片
- **本学期人数**：当前筛选范围内的学生总数
- **本学期/上学期均分**：综测平均分对比
- **需关注**：综测低于阈值的学生数
- **已关注**：手动标记关注的学生数
- **进步人数**：与上学期相比综测提升的人数

### 预警分布条
显示五级预警（安全🟢/关注🟡/预警🟠/危险🔴/严重⛔）各自人数，**点击可跳转筛选**。

### 班级排行
各班级按综测均分排名。前三名用金🥇银🥈铜🥉标识。

### 进步榜 / 优秀榜 TOP10
- 如有上学期数据：显示进步最大的10名学生（含变化值）
- 如仅有本学期：显示综测最高的10名

### 综测分布图
柱状图展示各分数段人数分布。有上学期数据时并排对比。

### 预警名单
列出所有低于阈值的预警学生，**点击学生行可查看详情**。

## 6. 班级分析

### 专业筛选
顶部可筛选特定专业（如仅看「顿河交」）。

### 班级综测排行图
横向柱状图，按综测均分从高到低排列。

### 班级详情表

- **「导出班级数据」按钮**导出该班Excel

## 7. 学生管理

### 搜索与筛选
- **搜索框**：输入学号或姓名，支持模糊匹配
- **班级筛选**：选择特定班级
- **预警等级筛选**：按五级预警筛选
- **素拓显示**：勾选后表格额外显示素拓分列
- **排序**：点击表头可排序（绩点/德育/综测等所有列）

### 表格信息
每个学生一行，包含：
- ☐ 对比勾选框（可勾选2-5人进行对比）
- ⭐ 关注标记（点击切换）
- 学号、姓名、班级
- 绩点、德育、素拓（可选）、综测
- 上学期综测 + 变化值（如有）
- 预警等级标签（五色）

颜色规则：**综测<60红色行**，**综测>85绿色行**。

### 批量操作
- **导出**：导出当前筛选结果到Excel
- **批量关注**：一键关注所有筛选结果
- **批量通知**：批量生成家长通知并下载
- **对比(X)**：勾选2-5人后点击，打开对比弹窗

### 学生对比
- 并排卡片展示选中学生的基本信息
- 柱状图对比绩点/德育/素拓/综测
- 如已导入成绩单：显示各人挂科情况对比

### 学生详情（点击姓名）
弹窗展示：
- 基本信息 + 四级成绩卡片（绩点/德育/素拓/综测）
- 预警等级标签
- 上学期对比 + 变化值
- 谈话记录（显示历史记录，可新增）
- 操作按钮：AI分析 / 关注 / 加标签 / **导出个人报告**

### 个人报告导出
点击「📋 导出报告」生成格式化的 Excel 个人成绩报告，包含：
- 学生基本信息
- 绩点/德育/素拓/综测及班级排名
- 与班级均值的对比
- 各科成绩明细（需先导入原始成绩单）
- 学期趋势

## 8. 成绩分析

### 功能说明
导入**原始成绩文件**（含各科成绩的表格，非综测汇总表），进行课程级别的深度分析。

### 导入成绩文件
1. 在「📂 导入原始成绩单」区域点击「选择文件」
2. 选择原始成绩文件（如 Module A 输入的 `专业成绩表-XX级.xls`）
3. 系统自动检测学期、年级、专业
4. （可选）手动设置年级和专业筛选
5. 点击「🔍 开始分析」

### 分析结果

#### 核心指标卡片
学生总数 / 课程数 / 平均分 / 学生挂科率 / 课程次挂科率 / 挂科人数

#### 成绩分布图
各分数段（<30/30-40/.../90-100）的学生人次分布。

#### 班级对比表
| # | 班级 | 人数 | 均分 | 挂科率 |

#### 课程挂科率排名
按挂科率从高到低排列所有课程。挂科率>30%的课程红色高亮。

#### 挂科学生列表
列出所有有挂科的学生，标注挂了几门、具体哪些课程。

#### 课程×班级热力图
- 行 = 班级，列 = 课程（TOP20挂科率）
- 颜色：🟢绿色（高分）→ 🟡黄色 → 🔴红色（低分）
- 悬停显示详细数据

### 数据联动
成绩分析数据会自动关联到通知工具的「挂科学生(课程)」筛选和「挂科科目详情」显示。

## 9. 预警中心

### 多级阈值设置
为绩点、德育、综测分别设置四级边界：

| 等级 | 含义 | 建议操作 |
|------|------|----------|
| 🟢 安全 | 高于安全线 | 正常关注 |
| 🟡 关注 | 介于关注线和预警线之间 | 观察趋势 |
| 🟠 预警 | 介于预警线和危险线之间 | 约谈学生 |
| 🔴 危险 | 介于危险线和严重线之间 | 立即约谈+通知家长 |
| ⛔ 严重 | 低于危险线 | 紧急处理 |

设置好后点击「💾 保存」。

### 预警分布
五色卡片展示各等级人数。**点击卡片**→跳转到学生管理并筛选对应等级。

### 预警详情列表
列出所有预警学生（低于任一阈值），含具体不达标的维度。

### 关注列表
显示所有手动标记⭐的学生，包含当前成绩和变化趋势。

### 标签管理
自定义标签（如「已谈话」「需家访」「心理关怀」等），关联到具体学生学号。标签显示在学生列表和详情中。

## 10. 通知工具

### 家长通知生成器

**第1步：选择目标学生**
| 筛选选项 | 说明 |
|----------|------|
| 全部学生 | 当前筛选范围内的所有学生 |
| 综测<60 | 综测不及格 |
| 德育≤60 | 德育分偏低的 |
| 已关注 | 手动加⭐的 |
| 挂科学生(课程) | 有单科挂科的（需先在成绩分析导入成绩单） |
| 预警等级学生 | 所有非「安全」等级的 |

**第2步：选择数据源**
选择使用哪个学期的数据（本学期/上学期/历史学期）

**第3步：勾选通知内容**
| ☑ 学生基本信息 | 姓名/学号/班级 |
| ☑ 学分绩点 | 绩点数值 |
| ☑ 德育分 | 德育分数值 |
| ☑ 素拓分 | 素拓分数值 |
| ☑ 综测成绩 | 综测数值 |
| ☑ 班级排名 | 在班级中的名次 |
| ☑ 挂科科目详情 | 具体挂科课程名+分数（需成绩单数据） |
| ☑ 全部科目成绩表 | 所有课程成绩（需成绩单数据） |
| ☑ 与班级均值对比 | 各项vs班级平均 |
| ☑ 学期变化趋势 | 与上学期对比 |
| ☑ 辅导员自定义评语 | 自行输入评语 |

**第4步：预览与导出**
- **生成通知文本**：在下方文本框预览（最多20人）
- **批量导出通知单**：下载为TXT文件，每位学生一份通知
- **预览示例**：快速查看第一条通知格式

### AI学生分析
输入学号 → 选择分析模式 → 点击分析：
- 📋 综合分析：全维度报告
- 💪 突出优势：列出2-3个优势领域
- 🔍 存在问题：诊断需改进领域
- 💡 提升建议：可操作的改进建议
- 🎯 雷达分析：五维评分+班级均值对标

### 智能分层
按综测（或绩点）将学生分为ABC三档：
- 🟢 A档（前30%）
- 🟡 B档（30%-70%）
- 🔴 C档（后30%）
- 可导出分层Excel

### 深度分析报告
生成统计报告（均值/标准差/分布/TOP/末尾/班级年级对比），可导出Excel。

## 13. 常见问题

**Q: 导入文件后没有数据？**
A: 确认导入的是综测输出文件（`.xlsx`），而非原始成绩文件。检查文件是否被其他程序占用。

**Q: 年级筛选没有选项？**
A: 确保已成功导入至少一个学期文件。导入后年级选项自动填充。

**Q: 班级排名为什么是错的？**
A: 排名基于全量数据计算。如果应用了年级筛选，排名仍是该班级内的真实排名。

**Q: 成绩分析导入后显示错误？**
A: 成绩分析需要**原始成绩文件**（含各科分数的.xls/.xlsx），不能导入综测汇总表。确保文件包含每门课程的成绩列。

**Q: 挂科学生筛选为空？**
A: 「挂科学生(课程)」需要先到成绩分析页导入原始成绩单并运行分析。

**Q: 家长通知中挂科科目显示不出来？**
A: 同样需要先在成绩分析页导入原始成绩单。

**Q: 大屏打开后是空白？**
A: 确保已导入本学期数据。

**Q: 谈话记录能导出吗？**
A: 谈话记录保存在备份文件中。通过「导出备份」可一并导出。
