# 学生综合测评系统 — 软件更新方法

> 版本 V8.2 · 开发者：陈雨昂

---

## 更新原理

本软件采用**纯本地文件替换**方式更新。不需要联网，不需要卸载旧版。

流程：选择新的exe → 软件自动替换 → 重启完成。

所有用户数据（设置、关注列表、标签、谈话记录、学期记录等）保存在 `data/` 文件夹中，**更新不会丢失数据**。

---

## 更新步骤（用户操作）

### 1. 获取新版exe
从开发者（陈雨昂）处获取最新的 `学生综合测评系统.exe`，放到电脑上任意位置。

获取方式：
- U盘拷贝
- 微信/QQ发送
- 共享文件夹
- 邮件附件

### 2. 打开软件
双击桌面快捷方式或exe文件，正常登录。

### 3. 进入更新页面
- **辅导员**：左侧菜单 → ⚙️ 设置 → 🔄 软件更新
- **秘书处**：左侧菜单 → ⚙️ 设置 → 帮助 → 🔄 软件更新

### 4. 选择更新文件
点击 **「📂 选择更新文件」** 按钮，在弹出的文件选择框中找到并选中刚才获取的新版exe文件。

系统会验证：
- 是否是exe文件
- 文件大小是否正常（>50MB）

### 5. 确认更新
验证通过后弹出确认对话框，显示文件名和大小。

点击「确定」→ 软件自动关闭 → 黑色命令行窗口出现 → **3-5秒后自动重新启动** → 完成更新。

### ⚠️ 注意事项
- 更新过程中请**不要手动关闭黑色窗口**
- 如杀毒软件弹出拦截提示，选择「允许」
- 更新完成后版本号显示在设置页「关于」区域

---

## 更新步骤（开发者操作）

### 1. 修改代码并测试
在开发环境中完成功能开发和测试。

### 2. 构建新版exe
```bash
cd "项目目录"
python -m PyInstaller --clean build.spec
```

构建完成后exe位于 `dist/学生综合测评系统.exe`

### 3. 更新版本号
修改 `config.py` 中的 `APP_VERSION`，以及 `web/js/main.js` 中的 `APP_VERSION`。更新 `showChangelog()` 中的更新日志。

### 4. 验证新exe
将 `dist/` 文件夹复制到另一台电脑或虚拟机中测试：
- 能否正常启动
- 能否正常登录
- 新功能是否正常工作
- 用旧版exe测试更新流程

### 5. 分发
将 `dist/学生综合测评系统.exe` 发送给用户。建议同时告知：
- 此版本的更新内容
- 是否有重大功能变化需要培训

---

## 回滚方法

如果新版有问题，可以手动回滚：

1. 关闭软件
2. 找到安装目录（通常在 `C:\Users\用户名\AppData\Local\学生综合测评系统\`）
3. 用旧版exe替换当前exe
4. 重新启动

或直接：
1. 卸载（运行 `uninstall.ps1`）
2. 用旧版分发包重新安装
