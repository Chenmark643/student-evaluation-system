## 1. 系统概述

本系统用于自动化计算顿河学院学生的**学分绩点**、**德育分**、**素质拓展分**和**综合测评成绩**。

四个模块按顺序使用：A（绩点）→ B（德育）→ C（素拓）→ D（综测），前一个模块的输出是后一个模块的输入。

## 4. 模块A：学分绩点计算

### 功能说明
将原始成绩表（.xls/.xlsx）转换为标准化学分绩点输出。

### 操作步骤

**第1步：选择原始成绩文件**
- 点击「批量选择文件」按钮
- 选择一个或多个原始成绩文件（如 `专业成绩表-顿河交2025级.xls`）
- 所选文件显示在列表中，可点击「清空列表」重新选择
- 支持同时选择不同专业、不同年级的文件，程序自动合并处理

**第2步：选择输出目录**
- 点击「浏览」选择输出目录（建议新建一个文件夹）

**第3步：设置处理选项**
- ☑ 体育课不计入学分绩点（默认勾选，建议保留）
- ☑ 自动生成专业排名（默认勾选）

**第4步：开始计算**
- 点击「开始计算」按钮
- 等待进度条完成

### 输出结果
- `学分绩点.xlsx`：每个学生的绩点数字（纯白底+黑字+宋体10pt）
- `学分绩点专业排名百分比.xlsx`：专业排名百分比

### 处理选项说明
- **体育课排除**：自动识别表头中含"体育""PE"等关键词的课程，从绩点计算中排除
- **专业排名**：按专业分组计算排名，输出到排名文件
- **等级制转换**：优=95、良=85、中=75、及格=65、不及格=50，自动转换为百分制

## 5. 模块B：德育分计算

### 功能说明
汇总多个数据源（旷课、卫生、团课等），结合实际评议分数，计算每位学生的德育总分。

### 操作步骤

**第1步：导入学生名单**
- 点击「浏览」选择 Module A 输出的 `学分绩点.xlsx`
- 导入后显示学生人数和班级信息

**第2步：导入各维度数据**

德育分由以下维度组成：

| 维度 | 数据来源 | 操作 |
|------|----------|------|
| 早晚自习旷课 | 纪检部旷课统计表 | 点击「选择」导入 |
| 课堂出勤 | 课堂旷课统计表 | 点击「选择」导入 |
| 宿舍卫生 | 宿舍卫生检查表 | 点击「选择」导入 |
| 教室卫生 | 教室卫生检查表 | 点击「选择」导入 |
| 团课出勤 | 团课统计表 | 点击「选择」导入 |
| 评议分 | 手动输入 | 在表格中直接录入 |

每个维度支持同时导入多个文件（如多个年级的宿舍卫生表）。

**第3步：自定义列与手动录入**
- 面板中显示所有可用维度列（如"早晚自习旷课""宿舍卫生扣分"等）
- 勾选需要纳入计算的列
- 对没有数据支撑的项目（如评议分），可在手动录入区直接输入分数

**第4步：预览与编辑**
- 点击「预览结果」查看计算后的数据表格
- 预览模式下可**双击单元格直接编辑**（按Enter确认）
- **Ctrl+Z** 可撤销编辑操作
- 点击「添加行」可增加新学生

**第5步：导出**
- 选择导出年级范围（全部/XX级）
- 选择导出列（勾选需要包含的列）
- 点击「导出Excel」

### 自定义表头
`德育分.xlsx` 输出文件的表头可自定义：
- 在「列选择」面板勾选/取消勾选需要的列
- 未勾选的列不会出现在输出文件中

### 年级筛选
- 导出前可通过年级筛选器选择仅导出特定年级
- 德育计算本身基于全部学生的花名册，筛选仅影响导出范围

## 6. 模块C：素拓分计算

### 功能说明
录入学生各类加分项目，自动应用上限阈值，生成素拓分汇总表。

### 操作步骤

**第1步：导入学生名单**
- 选择 Module A 输出的 `学分绩点.xlsx`
- 导入后自动识别班级信息

**第2步：添加加分记录**
- 选择目标学生（按班级筛选）
- 输入活动名称（如"全国大学生数学竞赛"）
- 选择类别（A类/B类/C类/D类/体育类/文艺活动类/学术类/志愿类/组织测评）
- 选择级别（国家级/省级/市级/校级/院级）
- 输入加分分数
- 系统会自动记忆已录入的活动名称，下次输入同类活动时自动填充类别和级别

**第3步：阈值管理**
各类型加分有上限：
- **默认阈值**：志愿类≤20分、组织测评≤10分
- 可以自定义添加新阈值
- 阈值为0表示不设上限
- 超出上限时，加分列合并显示上限值

**第4步：类别管理**
- 可以自定义添加新类别（如"创新创业类"）
- 可以删除不需要的类别
- 内置类别：A/B/C/D类、体育类、文艺活动类、学术类、志愿类、组织测评

**第5步：导出**
- 选择输出目录和文件名
- 点击「导出素拓分」
- 输出包含合并单元格格式的正式素拓分表格

### 活动记忆功能
系统自动保存活动→类别→分数的映射关系。下次输入已录过的活动名时，自动填充类别、级别和分数。

## 7. 模块D：综合测评计算

### 功能说明
将绩点（A）、德育（B）、素拓（C）三个模块的输出合并，按公式计算最终综测成绩和排名。

### 公式
- **无体育专项**：综测 = 绩点×0.7 + 德育×0.3 + 素拓×1.0
- **有体育专项**：综测 = 绩点×0.6 + 德育×0.3 + 体育×0.1 + 素拓×1.0

### 操作步骤

**第1步：导入三个文件**
- 绩点文件：选择 Module A 输出的 `学分绩点.xlsx`
- 德育文件：选择 Module B 输出的 `德育分.xlsx`
- 素拓文件：选择 Module C 输出的 `素拓分.xlsx`

**第2步：列映射**
- 系统自动检测文件表头
- 如有多张表（多sheet），在「列映射」区域确认学号列、姓名列、班级列、分数列的对应关系
- 通常会自动识别，无需手动调整

**第3步：体育选项**
- 如有体育专项成绩，勾选「包含体育成绩」
- 勾选后在弹出区域选择哪些专业/年级使用体育公式

**第4步：导出**
- 选择输出目录
- 选择导出年级范围
- 点击「开始计算」

### 输出结果
- `综测.xlsx`：综合测评成绩总表
- `综测排名百分比.xlsx`：排名百分比

### 智能表头检测
系统自动扫描文件表头，匹配「绩点」「德育」「素拓」「综测」等关键词，无需手动指定每一列。

## 8. 通用功能

### 记忆功能
- 切换模块不会丢失已填入的数据
- 关闭软件时自动保存所有工作状态
- 下次打开时自动恢复之前的文件路径和录入数据

- 内置 DeepSeek AI 助手

- API Key 已预配置，无需额外设置

## 9. 常见问题

**Q: 导出的Excel打开乱码？**
A: 用 Microsoft Excel 或 WPS 打开。系统输出标准宋体10pt，如字体缺失会自动替换。

**Q: 德育分计算结果与预期不符？**
A: 检查「列选择」面板，确认所有需要的维度列都已勾选。检查手动录入区的分数。

**Q: 素拓分超上限不合并？**
A: 确认阈值管理里该类别阈值设置正确。阈值为0表示不设上限。

**Q: 综测计算的排名显示错误？**
A: 检查三个输入文件是否都使用相同的学生名单（学号对应）。不同学期的学生可能有增减。

**Q: 如何批量处理多个年级？**
A: 模块A支持同时选择多个文件。模块B/C/D使用A的输出作为名单，无需分批操作。

**Q: 软件卡住不动了？**
A: 关闭软件重新打开，之前的数据会自动恢复（记忆功能）。

**Q: 杀毒软件拦截？**
A: 本软件使用 Python 打包，部分杀毒软件可能误报。请在杀毒软件中将软件加入信任列表。
