# 素拓预置规则库与材料加分抽屉设计规格

日期：2026-07-14  
状态：交互稿已确认，待书面复核

## 1. 目标与范围

依据工作区外的《素拓加分细则.md》，为素拓模块增加完整、可搜索的官方预置项目，并将细则中明确出现的数值上限全部预置到软件中。同时把“材料导入 → 选择学生 → 查看证明 → 添加分数”的拥挤三栏页面改为用户确认的“专注预览 + 加分抽屉”工作区。

本次不修改综测公式、学分绩点、德育分、评奖审核、游戏版和安装程序 UI。正式应用仍使用现有学院品牌体系。

## 2. 设计原则

1. 官方规则是默认建议，不替代人工认定。
2. 分值、类别、次数、上下限和系数都允许用户调整；超出细则范围时提示但不强行阻止。
3. 官方预置与用户模板分层保存，软件升级不能覆盖用户已有项目。
4. 每条加分保留原始分值、次数、系数、封顶前结果和封顶后结果，方便复核。
5. 材料预览应占主要空间，姓名列表和录入表单按需展开。

## 3. 预置规则库

### 3.1 数据结构

每个预置项目至少包含：

- `id`：稳定的内部标识；
- `name`：搜索与显示名称；
- `category`：用于统计和上限计算的细分类别；
- `grade`：级别、奖项、名次或认定等级；
- `score`：默认分值；
- `score_range`：需要学院认定时允许的建议区间；
- `tags`：别名与搜索关键词；
- `rule_note`：细则摘要；
- `cap_group`：所属封顶规则；
- `source`：`official` 或 `user`。

官方项目由代码内置并在加载时与用户映射合并。发生同名冲突时，用户项目优先；官方项目升级只补充缺失项，不覆盖用户编辑内容。

### 3.2 完整预置内容

按细则生成以下组合：

- 文艺活动：全国、省、市、校四级的特等奖、一等奖、二等奖、三等奖、优秀/鼓励奖及其他组委会奖；特等奖按一等奖加 1 分，其他奖按二等奖。
- 体育活动：全国、省、市、校四级的破纪录与第 1–8 名；团体替补可选择“降一等级”，最佳射手、MVP 等按二等奖逻辑。
- 表演活动：啦啦操/表演方队训练 1 分、节目演出 0.5 分。
- A、B、C、D 类竞赛：细则表格中全部级别与奖项组合；B 类常见赛事名称作为搜索别名。
- 其他学术竞赛：校级一、二、三等奖分别 0.8、0.6、0.4 分。
- 学术论文：自然科学与人文社会科学的全部期刊等级。
- 非学术文章：国家、省级/市厅级、校级、系级。
- 专利与软著：发明专利、实用新型、外观设计、软件著作权。
- 创业活动 3–5 分、国际学术会议 2–5 分，标为“需学院认定”。
- 学生工作：干部优秀/良好/合格，优秀宿舍宿舍长，社团优秀/良好/合格。
- 新生班主任助理：优秀、良好、合格，作为可与干部测评叠加的独立类别。
- 荣誉称号：国家、省、市、校、院五级；不预置由综测结果直接评出的优生、优干、优团、优团干加分。
- 社会实践考核：优秀、良好、合格及以下。
- 社会实践/志愿服务荣誉：国家、省部、校级。
- 比赛志愿服务、学院活动参与、寒暑假实践。
- 国家认可证书与其他技能培训证书；驾驶证不进入预置库。
- 未列项目：作为“待学院认定”的自定义入口，不给固定默认分。

### 3.3 系数与重复规则

- 与专业或俄语相关：抽屉提供默认关闭的“专业/俄语相关 ×2”开关，显示基础分和加倍后分值。
- 多人项目：提供“负责人 100% / 参与人 90% / 自定义贡献”选择。
- 同一项目或成果重复获奖：发现项目名称近似或材料重复时提示“建议只保留最高项”，允许用户查看并选择保留项。
- 分值区间默认填下限，并明确显示允许区间；用户修改后记录认定值。

## 4. 上限与取最高规则

删除目前不符合细则的“社会实践类总分上限 3 分”。不对社会实践荣誉 3.5 分进行错误截断。

预置以下明确规则：

| 规则 | 计算模式 | 上限 | 是否可与其他组叠加 |
| --- | --- | ---: | --- |
| 比赛志愿服务 | 每次 0.3，求和封顶 | 每学期 2 分 | 是 |
| 学院组织活动参与 | 每次 0.2，求和封顶 | 每学期 1 分 | 是 |
| 寒暑假社会实践 | 学院认定 1–2 分 | 2 分 | 是 |
| 技能培训与证书 | 每项 1 分，求和封顶 | 3 分 | 是 |
| 学生干部、班委、舍长、院校组织与社团任职评议 | 只取最高单项 | 3 分 | 同组不叠加 |
| 新生班主任助理 | 只取最高单项 | 2 分 | 可与学生干部组叠加 |

文艺、体育和学术竞赛中的“同一项目只取最高”不作为整个类别的总上限，而作为重复项目检查，避免不同项目之间被错误互相封顶。

每个上限显示“已使用 / 上限 / 本次后结果”。达到上限后保留原始明细，只调整计入总分的有效分。

## 5. 材料加分工作区

采用用户确认的 B 方案。

### 5.1 左侧学生队列

- 展开时显示搜索、姓名、学号、材料数量和完成状态；
- 可收合为头像/姓氏窄栏；
- 支持按班级、待审、处理中、已完成筛选；
- 切换学生时保留当前学生的录入草稿并提示未保存内容。

### 5.2 中央材料预览

- 作为页面最大区域；
- 顶部以标签切换该生的图片、PDF 和其他文件；
- 支持缩放、旋转、打开原文件、标记单份完成及全部完成；
- 当前学生、已审数量和下一位学生按钮始终可见。

### 5.3 右侧加分抽屉

- 可收合，窗口较窄时以覆盖式抽屉出现；
- 支持按名称、级别、奖项和别名搜索预置项目；
- 常用、文体、竞赛、成果、学生工作、实践志愿等快捷筛选；
- 选中项目后自动带出类别、等级、默认分、规则说明和上限；
- 用户可修改名称、类别、等级、分值、次数、贡献系数和专业/俄语倍数；
- 可将当前设置保存为个人模板，并选择是否在下次搜索时优先显示；
- 添加前显示“基础分 × 次数 × 系数”和封顶后的最终计入分；
- 抽屉底部显示当前学生已录入项目，支持编辑、删除和查看计算依据。

### 5.4 响应式规则

- 宽窗口：学生栏 + 大材料预览 + 固定抽屉；
- 中等窗口：学生栏自动变窄，抽屉仍固定；
- 小窗口：学生栏保持窄栏，抽屉覆盖在预览上方并可一键关闭；
- 不允许姓名、表单和按钮被压缩到无法阅读或操作。

## 6. 自定义与模板

- 官方模板只读，但可以“复制为个人模板”后修改；
- 个人模板支持新增、编辑、停用、删除、导入和导出；
- 用户可以新建自定义上限组，选择求和封顶或只取最高；
- 默认上限可临时调整，但必须显示“已偏离官方细则”的提示；
- 模板和自定义规则使用稳定版本号，升级时执行合并迁移。

## 7. 兼容与迁移

- 保留现有 `activity_mappings.json`，将其视为用户层；
- 对软件早期随包附带且内容仍与旧出厂值完全一致的错误示例（如旧四六级、计算机等级映射）执行一次替换；只要用户改过名称、类别、等级或分值，就视为用户数据并原样保留；
- 旧类别和旧加分记录继续可读，不自动改写历史结果；
- 新计算只对新建或用户主动重新计算的数据生效；
- 移除错误默认上限时，不删除用户手动创建的同名自定义规则，而是提示冲突并让用户选择；
- 打包版首次启动和已有用户升级都能获得新官方预置项目。

## 8. 异常处理

- 分值超出官方区间：显示黄色提示，允许用户确认继续；
- 同项目疑似重复：显示对比抽屉，默认建议保留最高项；
- 超过上限：保留原始分并明确显示有效分；
- 材料无法预览：仍允许打开原文件和手工录入；
- 用户模板损坏：忽略损坏项、保留其余数据，并提供错误说明。

## 9. 验收与测试

- 对细则中所有数值表进行参数化测试，确保级别/奖项/名次对应正确；
- 测试 0.3×次数封顶 2、0.2×次数封顶 1、寒暑假实践封顶 2、技能封顶 3；
- 测试学生干部只取最高且班主任助理仍可叠加；
- 测试国家级社会实践荣誉 3.5 不被总上限截断；
- 测试专业/俄语 ×2、参与人 90% 和重复项目提示；
- 测试用户模板优先且升级不覆盖；
- 测试材料查看器、二级弹窗与加分抽屉层级；
- 在 1400×900、1100×700 和更窄模拟宽度下检查内容无截断；
- 运行现有素拓、综测、桌面文件选择和打包测试，并启动成品 EXE 冒烟验证。
