# 顿河学院学生测评系统 A+C 融合 UI 设计规范

日期：2026-07-14  
状态：视觉预览已确认，等待书面规范确认后实施

## 1. 目标

把现有偏通用、偏浏览器化的界面统一为具有顿河学院辨识度的桌面工作应用。设计融合两套规则：

- A 的暖米白画布、四级绿色、舒适留白和耐用办公层级。
- C 的喷泉圆环、轨道线、悬浮胶囊和更有情绪价值的完成体验。

界面必须在长期处理学分、课程、德育分、综测和评奖资格时保持清晰、可靠，装饰不能削弱数据判断。

## 2. 品牌身份

### 2.1 核心视觉

- 深松绿表示工作空间、主操作和稳定秩序。
- 屋顶绿表示选中、确认和流程推进。
- 暖米白表示纸张、档案和学院环境。
- 砖红表示顿河学院身份、重要里程碑和完成仪式，不承担错误语义。
- 喷泉蓝仅用于少量信息提示。
- 喷泉圆环用于进度、完成涟漪、计数和背景轨迹。
- 广场几何仅用于欢迎页、工作中心和空状态的弱背景，不出现在密集表格后方。

### 2.2 Logo

使用现有清晰版顿河学院 Logo，至少出现在：

- 启动页与身份选择页。
- 主侧栏品牌区域。
- 欢迎页或工作中心主视觉。
- 完成仪式。
- 辅导员工作台页头。

Logo 保持原始比例，不拉伸、不裁切、不加低清放大。深色背景使用可读的描边或柔和阴影，禁止霓虹发光。

### 2.3 文案限制

产品界面不得出现“中外合作办学”“国际合作办学”“俄罗斯学院”“双校园”或类似关系表述。产品身份统一使用“顿河学院”。除非用户以后提供正式批准文案，否则不擅自描述机构关系。

## 3. 色彩与材质

### 3.1 核心色值

| 令牌 | 色值 | 用途 |
|---|---:|---|
| `school-green-950` | `#17372F` | 侧栏、深色主视觉 |
| `school-green-800` | `#245848` | 强选中、深色按钮 |
| `school-green-700` | `#2F6F57` | 主操作、焦点 |
| `school-green-100` | `#DCE9E2` | 选中浅底、确认洗色 |
| `brick-700` | `#963B3D` | 品牌标记、完成时刻 |
| `brick-100` | `#F2E2DF` | 品牌浅洗色 |
| `ivory-50` | `#F4F0E7` | 页面画布 |
| `ceramic-0` | `#FFFDF8` | 卡片、表格、模态内容 |
| `stone-200` | `#DCD5C9` | 边框、分隔线 |
| `ink-900` | `#19231F` | 正文和关键数据 |
| `ink-600` | `#68726E` | 次级文字 |

错误色使用独立的 `#C44343`，警告色使用 `#BD741D`，成功色使用 `#28795B`。所有异常必须同时提供图标或文字标签，不能只靠颜色。

### 3.2 液态玻璃使用边界

玻璃是层级材质，不是全局滤镜。

允许使用：

- 顶部栏和悬浮工具栏。
- 模态窗口外壳、抽屉外壳和状态胶囊。
- 欢迎页和工作中心的少量悬浮入口。
- 侧栏选中项的高光层。

禁止使用：

- 分数、学分、课程和排名数据单元格。
- 异常行、错误说明、评奖结论和字段映射主体。
- 大面积正文背景或每一张卡片。

玻璃表面采用暖白/松绿透明度、18–24px 模糊、1px 高光边框和两层低透明阴影。低性能或不支持 `backdrop-filter` 时回退为不透明陶瓷白或深松绿。

## 4. 字体与形状

- UI 正文：`Microsoft YaHei UI`, `Noto Sans SC`, `Segoe UI`, sans-serif。
- 学院展示标题：`STSong`, `Songti SC`, serif。
- 宋体仅用于欢迎标题、页面开场、完成文案和少量仪式性标题，表格与表单始终使用无衬线。
- 正文 14–16px，关键数据不得低于 13px；辅助元信息最低 11px。
- 普通卡片圆角 12–16px；主视觉和少量流程卡可用 24–36px。
- 主按钮和状态胶囊使用圆角胶囊；数据编辑控件使用 8–10px 圆角。

## 5. 动效系统

### 5.1 非线性缓动

- 页面进入：`cubic-bezier(.16,1,.3,1)`，轻微位移与缩放，450–700ms。
- 卡片错峰：每项相差 60–90ms，总时长不超过 800ms。
- 按钮回弹：`cubic-bezier(.34,1.56,.64,1)`，按下缩放约 `0.95`，释放回弹。
- 抽屉/模态：惯性展开，避免线性淡入。
- 进度圆环：旋转与缩放组合，仅首次进入或进度变化时播放。
- 主视觉轨道可做轻微指针视差，移动幅度不超过 12px，不影响文字阅读。

### 5.2 性能与可访问性

- 优先动画 `transform` 与 `opacity`，避免持续动画布局属性。
- 持续背景动画最多一处，并在页面非活动时停止。
- 遵循 `prefers-reduced-motion: reduce`，关闭视差、漂移、错峰和闪光扫过，仅保留瞬时状态切换。
- 低性能环境禁用高强度模糊和大范围阴影。

## 6. 页面覆盖范围

本次是正式应用的全局改版，不修改独立游戏程序和安装程序。

必须统一：

1. 启动页、身份选择、欢迎页。
2. 工作中心和各模块入口。
3. 主侧栏、顶部栏、专业与学期状态。
4. 学分绩点来源上传、课程审核、班级展开和个人差异。
5. 德育分制作/上传、素拓和综合测评页面。
6. 检查与字段映射全屏窗口及异常处理。
7. 评奖资格核验的模板、人员选择、文件上传和姓名抽屉。
8. 辅导员工作台。
9. 设置、模态窗口、Toast、空状态、加载状态和完成仪式。
10. 浅色与深色主题。

## 7. 数据密集页面规则

- 班级是学分绩点审核的第一层，学生是第二层，课程是第三层。
- 公共课程可折叠，个人差异始终显示数量、课程名、学分和原因标签。
- “重修”“转专业”“多修”“缺课”“无效学分”使用语义警告，不使用品牌砖红。
- 映射异常必须显示原值、位置、失败原因和处理方式：修正、设为空、忽略。
- 表格横向空间不足时优先换行、折叠次要说明或横向滚动，不缩小关键数字。
- 长文件名、长课程名、13 门以上课程和大量候选人必须保持可操作。

## 8. 实施结构

- 新建一个最后加载的全局主题层，集中维护品牌令牌、玻璃材质、动效和兼容回退。
- 复用现有 HTML 与业务脚本，不在视觉改版中重写计算逻辑。
- 用页面根类限定高风险覆盖，避免通用选择器污染所有组件。
- 将 Logo 引用统一到现有高清资源。
- 逐页面替换现有蓝色 Apple 风格和过度玻璃规则；数据区域恢复实体表面。
- 保留深色主题，通过同一语义令牌生成暗色变体。

## 9. 验收标准

- 所有现有功能和文件选择能力保持可用。
- 无禁用机构关系文案。
- 顿河学院 Logo 在指定入口清晰可见。
- 异常、错误和品牌砖红不会混淆。
- 125% 和 150% Windows 缩放下无截断；窗口缩窄后仍可完成操作。
- 字段映射、GPA 审核和评奖抽屉中的密集内容不溢出。
- `prefers-reduced-motion` 生效。
- 不支持玻璃模糊时界面仍可读。
- 自动化契约测试、后端测试和桌面启动冒烟测试通过。

## 10. 非目标

- 不修改计算公式、Excel 识别和导出格式。
- 不修改独立游戏程序。
- 不修改本轮已完成的安装程序视觉。
- 不引入在线字体、在线图片或运行时网络依赖。
