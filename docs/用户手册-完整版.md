## 1. 系统概述

### 1.1 软件简介

顿河学院学生综合测评系统是一套面向高校辅导员的**桌面端学生成绩管理与综测评算工具**。它将学分绩点计算、德育评分、素拓管理、综测排名等核心工作流整合为一体化平台，取代传统的 Excel 手工操作。

### 1.2 核心功能

| 功能模块 | 适用角色 | 说明 |
|----------|----------|------|
| 学分绩点计算（A） | 秘书处 | 原始成绩表 → 标准化绩点输出 |
| 德育分计算（B） | 秘书处 | 多源数据（旷课/卫生/团课/评议）→ 德育总分 |
| 素质拓展分计算（C） | 秘书处 | 加分录入 + 上限管控 + 材料归档 |
| 综合测评计算（D） | 秘书处 | 绩点+德育+素拓 → 综测排名 |
| 数据总览与分析 | 辅导员 | 多维度可视化、年级/班级/学生对比 |
| 预警与通知 | 辅导员 | 五级预警、家长通知自动生成、班会大屏 |

### 1.3 工作流程

```
秘书处：A(绩点) → B(德育) → C(素拓) → D(综测) → 导出综测文件
                                                      ↓
辅导员：导入综测文件 → 总览/分析/预警/通知/大屏
```

前一个模块的输出是后一个模块的输入，四个模块按顺序执行。

## 2. 安装与启动

### 2.1 系统要求

| 项目 | 最低配置 |
|------|----------|
| 操作系统 | Windows 10 / Windows 11（64位） |
| 内存 | 4 GB |
| 硬盘空间 | 200 MB |
| 浏览器 | Chrome 或 Edge（系统自动检测） |
| 办公软件 | Microsoft Excel 2016+ 或 WPS Office |

### 2.2 安装步骤

**方法一：安装包安装（推荐）**

1. 解压 `学生综合测评系统-秘书处版本.zip` 或 `学生综合测评系统-辅导员版本.zip` 到任意目录
2. 进入解压后的 `dist` 文件夹
3. 右键 `install.bat` →「以管理员身份运行」
4. 桌面和开始菜单自动创建快捷方式
5. 安装完成

**方法二：直接运行**

1. 解压后双击 `直接运行.bat`
2. 或直接双击 `顿河学院学生测评管理软件.exe`

### 2.3 卸载

右键 `uninstall.ps1` →「使用 PowerShell 运行」即可清除快捷方式。直接删除软件目录即可完全卸载（软件不写注册表，不残留文件）。

### 2.4 首次启动

首次启动可能需要 10-30 秒，系统会自动检测并打开 Chrome 或 Edge 浏览器窗口。**不要关闭弹出的命令行黑窗**（它是后台服务）。

## 5. 秘书处：模块A — 学分绩点计算

### 5.1 功能说明

将原始成绩表（各专业导出的 `.xls` / `.xlsx` 文件）转换为标准化学分绩点。支持等级制自动转换、体育课排除、专业排名生成。

### 5.2 操作步骤

**第1步：选择原始成绩文件**

1. 点击「批量选择文件」按钮
2. 选择一个或多个原始成绩文件（如 `专业成绩表-顿河交2025级.xls`）
3. 所选文件显示在列表中，可点击「清空列表」重新选择
4. **支持跨专业、跨年级同时选择**，程序自动合并处理

**第2步：选择输出目录**

点击「浏览」选择输出目录（建议新建空文件夹）。

**第3步：设置处理选项**

| 选项 | 说明 | 建议 |
|------|------|------|
| 体育课不计入绩点 | 自动识别"体育""PE"等关键词并排除 | ✅ 勾选 |
| 自动生成专业排名 | 按专业分组计算排名百分比 | ✅ 勾选 |

**第4步：开始计算**

点击「开始计算」，等待进度条完成。

### 5.3 输出文件

| 文件名 | 内容 |
|--------|------|
| `学分绩点.xlsx` | 每个学生的绩点数值（宋体10pt，纯白底黑字） |
| `学分绩点专业排名百分比.xlsx` | 按专业分组的排名百分比 |

### 5.4 等级制转换规则

| 原始等级 | 转换分数 |
|----------|----------|
| 优 / 优秀 | 95 |
| 良 / 良好 | 85 |
| 中 / 中等 | 75 |
| 及格 / 合格 / 通过 | 65 |
| 不及格 / 不合格 | 45 |

## 6. 秘书处：模块B — 德育分计算

### 6.1 功能说明

汇总多个数据源（旷课、卫生、团课、评议等）计算每位学生的德育总分。支持多文件合并、自定义列选择、手动录入和预览编辑。

### 6.2 德育评分维度

| 维度 | 数据来源 | 扣分规则 |
|------|----------|----------|
| 早晚自习旷课 | 纪检部统计表 | 每次 -2 分 |
| 课堂出勤 | 课堂旷课统计表 | 每次 -2 分 |
| 宿舍卫生 | 宿舍卫生检查表 | 按检查扣分 |
| 教室卫生 | 教室卫生检查表 | 按检查扣分 |
| 团课出勤 | 团课统计表 | 每次 -2 分 |
| 评议分 | 手动录入 | 加分项 |

基础分：**80 分**，在此基础上加减。

### 6.3 操作步骤

**第1步：导入学生名单**

选择 Module A 输出的 `学分绩点.xlsx` 作为花名册。导入后显示学生人数和班级信息。

**第2步：导入各维度数据**

逐个维度点击「选择」导入对应统计表。每个维度支持同时导入多个文件（如多个年级的卫生表）。系统自动按学号匹配学生。

**第3步：自定义列与手动录入**

- 勾选需要纳入计算的维度列
- 评议分等无文件支撑的项目在手动录入区直接输入分数
- 支持右键添行、删除行

**第4步：预览与编辑**

- 点击「预览结果」查看计算后的数据表格
- **双击单元格**直接编辑（Enter 确认）
- `Ctrl + Z` 撤销编辑
- 支持添加新学生行

**第5步：导出**

- 选择导出年级范围（全部 / 指定年级）
- 勾选需要包含的列
- 点击「导出 Excel」

## 7. 秘书处：模块C — 素质拓展分计算

### 7.1 功能说明

录入学生各类加分项目（竞赛、论文、学生工作、社会实践、技能证书等），自动应用上限阈值，生成素拓分汇总表。

模块C 支持三种工作模式：

| 模式 | 适用场景 |
|------|----------|
| 🤖 自动计算 | 逐人录入加分项目，系统自动汇总并应用上限 |
| ✋ 辅助人工 | 导入已填好加分的半成品素拓表，系统解析并汇总 |
| 📦 材料导入 | 班级 ZIP 材料包解压归档 + 在线审核加分 |

### 7.2 加分类别与等级

| 类别 | 包含内容 | 典型等级 |
|------|----------|----------|
| 文体艺术类 | 文艺活动、体育活动、荣誉称号 | 国家级/省级/市级/校级/院级 |
| 学术竞赛类 | A/B/C/D类学科竞赛 | 国家级/省部级/校级/院级 |
| 学术成果类 | 论文、专利、软著、文章 | 按期刊等级/专利类型 |
| 学生工作类 | 班委、学生会、社团任职 | 优秀/良好/合格 |
| 社会实践类 | 志愿服务、社会实践 | 国家级荣誉/省部级荣誉等 |
| 技能证书类 | 四六级、计算机等国家级证书 | 国家级证书/其他证书 |

### 7.3 默认上限阈值

| 阈值名称 | 上限 | 模式 |
|----------|------|------|
| 社会实践类上限 | 3 分 | 求和封顶 |
| 学生工作类上限 | 3 分 | 取最高分 |
| 技能证书类上限 | 3 分 | 求和封顶 |

可自定义添加上限规则（见 7.6 节）。

### 7.4 自动计算模式操作

1. 导入花名册（Module A 输出的 `学分绩点.xlsx`）
2. 选择班级 → 学生
3. 输入活动名称（系统自动记忆，下次输入自动填充）
4. 选择类别和等级
5. 输入分数
6. 点击「+ 添加」
7. 可重复添加同一学生的多个加分项目
8. 完成后导出

### 7.5 材料导入模式操作（📦）

这是 V8.2 新增的一站式材料处理流程。

**第1步：准备材料**

辅导员收集各班班长发来的 ZIP 压缩包（内含每位学生的证明材料）。

**第2步：解压归档**

1. 点击「📁 浏览选择」选择班级 ZIP 包（可多选）
2. 选择解压输出目录
3. 点击「🚀 开始智能解压」
4. 系统自动识别班级名称和学生姓名，按 `班级/学生/文件` 结构归档
5. 自动解压嵌套 ZIP/RAR/7z 压缩包
6. 自动清理单层嵌套文件夹（如 `张三/张三/证书.jpg` → `张三/证书.jpg`）

**第3步：材料管理**

解压完成后进入树形文件管理器：
- 班级 → 学生 → 文件（树形层级）
- 支持展开/折叠所有
- 文件类型图标：🖼️ 图片、📕 PDF、📎 其他
- 进度条显示各班审核进度
- 支持标记文件审核状态：✅ 已完成 / ⬜ 待处理

**第4步：查看并加分**

1. 展开学生 → 点击「📄 查看并加分」
2. 弹出材料查看器：左侧文件列表，右侧预览区，最右侧加分面板
3. **支持图片/PDF/文本文件在软件内直接预览**
4. 点击左侧文件即可预览，选择加分项目并添加分数
5. 支持一键外部打开（用系统默认程序查看）

**第5步：导出**

学生全部审核完毕后，点击「导出素拓分数」。

### 7.6 阈值管理

点击「⚠️ 上限」按钮管理加分上限：

1. 点击「+ 添加上限」
2. 输入名称（如"国家级证书上限"）
3. 选择计算模式：**Σ 求和封顶** 或 **🏆 取最高分**
4. 设置上限值
5. 勾选适用的加分类别
6. 点击添加

默认阈值不可删除，自定义阈值可随时删除。

### 7.7 辅助人工模式操作

适用于已填写加分但缺汇总的"半成品"素拓表：

1. 选择半成品素拓表（`.xlsx`）
2. 点击「🔍 解析汇总」
3. 系统自动识别加分列并汇总
4. 预览确认后导出

### 7.8 进度保存与恢复

材料导入模式下支持保存/恢复审核进度：

- **💾 保存进度**：将当前加分数据保存为 JSON 文件
- **📥 恢复进度**：从 JSON 文件恢复之前的加分数据
- 进度自动关联到学生，不会因软件关闭丢失

### 7.9 花名册匹配

导入花名册后，系统自动按姓名匹配材料目录中的学生与花名册中的学号。未匹配的学生显示「⚠️匹配」按钮，可手动选择对应学号。

## 8. 秘书处：模块D — 综合测评计算

### 8.1 功能说明

将绩点（A）、德育（B）、素拓（C）三个模块的输出合并，按公式计算最终综测成绩和排名。

### 8.2 综测公式

**无体育专项（默认）：**

```
综测 = 绩点 × 0.7 + 德育 × 0.3 + 素拓 × 1.0
```

**有体育专项（勾选后）：**

```
综测 = 绩点 × 0.6 + 德育 × 0.3 + 体育 × 0.1 + 素拓 × 1.0
```

### 8.3 操作步骤

**第1步：导入三个文件**

| 文件 | 来源 |
|------|------|
| 绩点文件 | Module A → `学分绩点.xlsx` |
| 德育文件 | Module B → `德育分.xlsx` |
| 素拓文件 | Module C → `素拓分.xlsx` |

**第2步：列映射确认**

系统自动检测文件表头并匹配学号列、姓名列、班级列、分数列。通常无需手动调整，确认即可。

**第3步：体育选项（可选）**

如有体育专项成绩：
1. 勾选「包含体育成绩」
2. 在弹出的区域中选择哪些专业/年级使用体育公式
3. 导入体育成绩文件

**第4步：导出**

1. 选择输出目录
2. 选择导出年级范围
3. 点击「开始计算」

### 8.4 输出文件

| 文件名 | 内容 |
|--------|------|
| `综测.xlsx` | 综合测评成绩总表（含各维度明细） |
| `综测排名百分比.xlsx` | 按班级/专业的排名百分比 |

### 8.5 数据验证

导出前系统自动检查：
- 三个输入文件的学生是否一致（学号匹配）
- 缺失学生自动标记
- 异常分数高亮提示

## 9. 辅导员：数据总览

### 9.1 导入数据

进入工作台后首先需要导入综测文件：

1. 点击顶栏「📗 本学期」旁的「选」→ 选择本学期综测文件
2. 输入学期标签（如 `2025-2026-1`）
3. 点击顶栏「📕 上学期」旁的「选」→ 选择上学期综测文件
4. 如需更多历史学期，点击「+」添加

### 9.2 筛选器

导入后顶栏筛选器自动填充：

| 筛选器 | 说明 |
|--------|------|
| 年级 | 如 24级、23级 — 自动从班级名提取 |
| 专业 | 如 顿河交、顿河土、顿河信、国电 |
| 班级 | 如 顿河交241 — 根据年级和专业联动过滤 |

三个筛选器可组合使用。筛选状态自动保存，下次启动恢复。

## 18. 常见问题与故障排除

### 18.1 安装与启动

**Q: 双击 exe 没反应？**

A: 稍等 10-30 秒，首次启动较慢。如果超过 1 分钟仍无反应，检查杀毒软件是否拦截（部分杀毒软件误报 Python 打包程序，请加入信任列表）。

**Q: 弹出命令行黑窗后浏览器没打开？**

A: 不要关闭黑窗。确认 Chrome 或 Edge 浏览器已安装。如仍无法启动，尝试以管理员身份运行。

**Q: 浏览器打开了但显示"无法连接"？**

A: 关闭软件，检查端口是否被占用。重启电脑后再试。

### 18.2 文件导入

**Q: 导入 Excel 文件后没有数据？**

A: 确认导入的是正确的文件类型（综测输出文件是 `.xlsx`，原始成绩文件可能是 `.xls`）。检查文件是否被其他程序（Excel/WPS）占用。

**Q: 成绩分析导入后显示错误？**

A: 成绩分析需要**原始成绩文件**（含各科分数的 `.xls`/`.xlsx`），不能导入综测汇总表。

**Q: 德育分计算结果与预期不符？**

A: 检查「列选择」面板，确认所有维度列都已勾选。检查手动录入区的分数是否正确。

### 18.3 计算与导出

**Q: 素拓分超上限没有合并？**

A: 确认阈值管理中该类别阈值设置正确。阈值为 0 表示不设上限。

**Q: 综测排名显示错误？**

A: 检查三个输入文件是否使用相同的学生名单。不同学期的学生可能有增减。

**Q: 导出 Excel 打开是乱码？**

A: 请用 Microsoft Excel 或 WPS 打开。系统输出标准宋体 10pt，如字体缺失系统会自动替换。

### 18.4 辅导员功能

**Q: 年级筛选没有选项？**

A: 确保已成功导入至少一个学期文件。导入后年级选项自动填充。

**Q: 挂科学生筛选为空？**

A: 「挂科学生(课程)」需要先到成绩分析页导入原始成绩单并运行分析。

**Q: 家长通知中挂科科目不显示？**

A: 同样需要先在成绩分析页导入原始成绩单。

**Q: 大屏打开后空白？**

A: 确保已导入本学期数据。

### 18.5 材料导入（素拓模块C）

**Q: 解压后学生名字不对？**

A: 系统按文件夹名称自动检测姓名。如果 ZIP 包内的文件夹命名不规范，请手动在材料管理界面修改：点击「✏️ 重命名」按钮。

**Q: 二级文件夹下的文件打不开？**

A: V8.2 已修复此问题。如果仍有问题，将软件更新到最新版本。

**Q: 学生没有匹配到花名册？**

A: 点击学生名旁的「⚠️匹配」按钮，手动选择花名册中对应的学生。

### 18.6 其他

**Q: 软件卡住了？**

A: 关闭软件重新打开，之前的数据会自动恢复。如反复出现，将 `data` 文件夹备份后删除，重新导入数据。

**Q: 如何批量处理多个年级？**

A: 模块 A 支持同时选择多个文件。模块 B/C/D 使用 A 的输出作为名单，无需分批操作。

**Q: 谈话记录可以导出吗？**

A: 谈话记录保存于备份 JSON 文件中。通过「导出备份」可一并导出。
