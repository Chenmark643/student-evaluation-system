## 1. 设计系统

### 1.1 配色方案

#### 深色主题（默认）

**背景层级**：`#0a1020`（根）→ `#101830`（主）→ `#182040`（辅）→ `#1e2850`（第三级）

**强调色**：
- 紫色 `#6c5ce7` — 主按钮、激活状态、焦点环
- 青色 `#00cec9` — 次要按钮、结果统计、AI面板
- 金色 `#fdcb6e` — 素拓模块、警告

**语义色**：
- 成功 `#00b894` | 警告 `#fdcb6e` | 错误 `#e17055` | 危险 `#d63031` | 信息 `#74b9ff`

**文字色**：`#e8e8f0`（主）→ `#8892b0`（辅）→ `#4a5270`（弱）

**模块卡片渐变色**：绩点(紫)、德育(青)、素拓(金)、综测(橙)

#### 浅色主题

背景反转为白色系 `#f0f2f5` → `#ffffff` → `#f5f6f8`，文字反转为深色 `#1a1d26` → `#555b6e` → `#8b919e`，强调色保持不变。

### 1.2 字体

- **正文**：`-apple-system, BlinkMacSystemFont, 'Microsoft YaHei', 'PingFang SC', sans-serif`，基准 14px
- **等宽**：`'JetBrains Mono', 'Cascadia Code', 'Fira Code', 'Consolas', monospace`
- **字号阶梯**：12 / 13 / 14 / 16 / 18 / 24 / 32 px

### 1.3 圆角系统

`4px`（小）→ `6px` → `8px`（按钮/输入框）→ `12px`（卡片）→ `16px`（大卡片）→ `9999px`（胶囊/进度条）

### 1.4 阴影系统

深色：`0 2px 8px rgba(0,0,0,0.3)` 到 `0 8px 48px rgba(0,0,0,0.4)`
发光：`0 0 20px rgba(108,92,231,0.3)`（紫色）/ `0 0 20px rgba(0,206,201,0.25)`（青色）

### 1.5 毛玻璃效果（Glassmorphism）

全应用使用 `backdrop-filter: blur()` + 半透明背景：
- 侧边栏：`blur(24px) saturate(1.4)`，背景 `rgba(10,14,26,0.75)`
- 顶栏：`blur(20px) saturate(1.3)`，背景 `rgba(10,14,26,0.7)`
- 模块卡片：`blur(16px) saturate(1.2)`，背景 `rgba(17,22,39,0.65)`
- 弹窗卡片：`blur(24px) saturate(1.5)`，背景 `rgba(17,22,39,0.85)`
- 输入框：`blur(8px)`，背景 `rgba(13,17,32,0.6)`

### 1.6 动画系统

| 动画名 | 时长 | 效果 |
|--------|------|------|
| `fadeSlideIn` | 0.25-1.5s | 淡入+上移12px |
| `modalSlideIn` | 250ms | 缩放0.96→1 + 下移16px |
| `toastSlideIn` | 300ms | 从右侧滑入 |
| `toastSlideOut` | 250ms | 滑出右侧 |
| `float` | 2.5s 循环 | 上下浮动6px |
| `glowPulse` | 2-3s 循环 | 阴影脉冲 |
| `shimmer` | 1.5-2s 循环 | 光泽扫过 |
| `pulse` | 1.5s 循环 | 透明度脉冲 |

### 1.7 Z-Index 层级

`0` 背景粒子 → `1` 主界面 → `10` 侧边栏 → `200` AI面板 → `1000` Toast → `4000` 辅导员页 → `5000` 欢迎页 → `10000` 启动画面/弹窗 → `20000` 登录页

## 7. 共用组件

### 7.1 按钮

| 类型 | 类名 | 背景 | 文字色 | 特效 |
|------|------|------|--------|------|
| 主按钮 | `.btn-primary` | 紫色渐变 | 白色 | 发光阴影+悬停上浮1px |
| 次按钮 | `.btn-secondary` | 半透明+毛玻璃 | 主色 | 紫色边框 |
| 青色按钮 | `.btn-teal` | 青色15%透明 | 青色 | 悬停发光 |
| 幽灵按钮 | `.btn-ghost` | 透明 | 辅色 | 悬停高亮背景 |
| 危险按钮 | `.btn-danger` | 红色12%透明 | 红色 | — |

**尺寸**：默认 13px/10-20px | 小号 12px/6-12px | 大号 16px/14-28px

**状态**：默认 / 悬停 / 按下(缩放0.97) / 禁用(50%透明) / 处理中(脉冲动画)

### 7.2 输入框

毛玻璃背景+8px模糊，圆角8px，13px字体。
- **默认**：半透明背景，紫色细边框
- **聚焦**：紫色边框+3px紫色光环
- **有文件**（`.has-file`）：青色边框+主色文字
- **只读**：等宽字体，溢出省略号

下拉框有自定义下三角箭头（内联SVG Data URI）

### 7.3 Toast 通知

右上角固定（z-index 1000），从右滑入(300ms)，4秒后滑出(250ms)。
- 成功=绿色左边框 ✓ | 错误=红色 ✗ | 警告=金色 ⚠ | 信息=蓝色 ℹ
- 图标+消息+关闭按钮，max-width 400px

### 7.4 弹窗（Modal）

- **遮罩**：60%暗色+8px模糊，点击关闭
- **卡片**：毛玻璃（24px模糊+1.5饱和度），缩放+下滑进入动画(250ms)
- **头部**：16px粗体标题+X关闭按钮
- **主体**：24px内边距
- **底部**：右对齐按钮组，顶部分割线

### 7.5 数据表格

- 表头：粘性定位，`#1e2850`背景，12px大写粗体
- 行：悬停高亮，交替行有微弱紫色底色
- 特殊行：`.row-danger`（红色底，综测<60）、`.row-excellent`（绿色底，综测>85）
- 数字列：等宽居中，公式列：紫色等宽

### 7.6 进度条

- 轨道：6px 高，`#1e2850`背景，全圆角
- 填充：紫青渐变，宽度过渡300ms
- 光泽动画：白色半透明光泽扫过（2s循环）
- 文字：左侧状态+右侧百分比（12px等宽）

### 7.7 文件选择器

- 输入框（只读，等宽，溢出省略号）+ 浏览按钮
- 多文件列表：每行含序号(28px灰色)+文件名(12px等宽)+红色X删除钮
- 空状态："未选择文件"（13px灰色）
