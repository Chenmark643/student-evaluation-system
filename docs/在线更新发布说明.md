# 程序在线更新发布说明

从 v14.0.9 开始，Windows 客户端可以在程序内完成版本检测、下载、校验、替换和重启。

## 使用者需要做什么

第一次安装 v14.0.9 时仍需发送一次“轻量安装包”。之后有新版本时，使用者打开程序即可收到更新提醒，不需要重新下载安装包。

## 开发者如何发布新版

1. 完成功能修改和测试，运行 `python tools/set_release_version.py 14.1.2` 同步修改版本号。
2. 将代码推送到与版本一致的发布分支，例如 `release-v14.1.2`。Windows 工作流会自动构建并发布对应 Release。
3. 也可以推送 `v14.1.2` 标签，或打开 GitHub 仓库的 **Actions → Build Windows app → Run workflow** 手动发布。
4. 手动运行时，输入与 `config.py` 一致的版本号，并保持“发布为最新 Release”为勾选状态。
5. 等待构建完成。GitHub 会自动发布主程序、SHA-256 校验文件和 `update-windows.json`。同一版本标签如果已经指向其他提交，工作流会拒绝覆盖发布资产。

客户端优先读取 GitHub 最新 Release 信息。若中国境内无法直连 GitHub，会分别读取以下两个镜像中的版本清单：

- `https://ghfast.top/https://github.com/Chenmark643/student-evaluation-system/releases/latest/download/update-windows.json`
- `https://ghproxy.net/https://github.com/Chenmark643/student-evaluation-system/releases/latest/download/update-windows.json`

只有两个镜像返回的 JSON 完全一致时，客户端才接受镜像清单。随后下载程序时依次尝试 `ghfast.top`、`ghproxy.net` 和 GitHub 原始地址；自定义清单地址仍可通过 `DONCOLLEGE_UPDATE_MANIFEST_URLS` 配置。

不要删除 Release 中的以下三个文件：

- `DonCollege-Student-Evaluation-windows-x64.exe`
- `DonCollege-Student-Evaluation-windows-x64.exe.sha256`
- `update-windows.json`

## 文件体积

- 在线更新文件：约 43MB，日常发布使用。
- 轻量安装包：约 88MB，仅首次安装或环境修复时使用。
- 完整离线安装包：约 282MB，仅在电脑缺少 WebView2 且无法联网时使用。

下载后的临时文件会放在应用数据目录的 `updates` 文件夹中。客户端会核对清单版本、文件大小和 SHA-256，复制后再次校验，再通过 Windows 原子替换更新主程序；启动健康检查失败时会恢复备份。新版确认正常后，替换脚本会删除下载目录和旧程序备份，避免长期占用磁盘。
