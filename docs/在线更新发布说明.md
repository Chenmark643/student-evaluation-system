# 程序在线更新发布说明

从 v14.0.9 开始，Windows 客户端可以在程序内完成版本检测、下载、校验、替换和重启。

## 使用者需要做什么

第一次安装 v14.0.9 时仍需发送一次“轻量安装包”。之后有新版本时，使用者打开程序即可收到更新提醒，不需要重新下载安装包。

## 开发者如何发布新版

1. 完成功能修改和测试，运行 `python tools/set_release_version.py 14.1.0` 同步修改版本号。
2. 将代码推送到 GitHub 仓库。
3. 打开 GitHub 仓库的 **Actions → Build Windows app → Run workflow**。
4. 输入与 `config.py` 一致的版本号，保持“发布为最新 Release”为勾选状态。
5. 等待构建完成。GitHub 会自动发布主程序、SHA-256 校验文件和 `update-windows.json`。

客户端固定读取：

`https://github.com/Chenmark643/student-evaluation-system/releases/latest/download/update-windows.json`

不要删除 Release 中的以下三个文件：

- `DonCollege-Student-Evaluation-windows-x64.exe`
- `DonCollege-Student-Evaluation-windows-x64.exe.sha256`
- `update-windows.json`

## 文件体积

- 在线更新文件：约 43MB，日常发布使用。
- 轻量安装包：约 88MB，仅首次安装或环境修复时使用。
- 完整离线安装包：约 282MB，仅在电脑缺少 WebView2 且无法联网时使用。

下载后的临时文件会放在应用数据目录的 `updates` 文件夹中。新版安装成功后，替换脚本会删除下载目录和旧程序备份，避免长期占用磁盘。
